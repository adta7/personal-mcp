Most personal sites that claim to be "API-accessible" are a site plus a bolted-on `/api`
folder that drifts out of sync within a month. This one is built so that drift is
structurally impossible: `content/` holds the facts, `src/core/` resolves them, and the
website, the JSON API, and the MCP server are three thin adapters over the same resolvers.

The dependency direction is enforced by ESLint rather than by discipline — `src/core`
cannot import React or Next, so a fact can never be implemented twice.

There is no database. Content is typed files in git, validated by Zod at build time, which
means malformed data fails CI instead of throwing in production.
